# Role–permission matrix

_Generated by `npx tsx scripts/gen-permission-matrix.ts` from `src/modules/rbac/permissions.ts`. These are the seeded defaults; administrators may adjust role permissions in Admin › Roles within the enforced guardrails._

- **SA** = Super Administrator (KATDICT_STAFF, privileged: MFA enforced) — System administration. Deliberately excluded from operational approvals (separation of duties).
- **DG** = Director / Director-General (KATDICT_STAFF, privileged: MFA enforced) — Executive oversight and executive-level approvals.
- **OPS** = KATDICT Operations Administrator (KATDICT_STAFF, privileged: MFA enforced) — Triage, assessment, assignment, delivery tracking and closure.
- **HOD** = Department Head (KATDICT_STAFF) — Departmental work queue, officer assignment and departmental approvals.
- **OFF** = Project Manager / ICT Officer (KATDICT_STAFF) — Delivers assigned projects.
- **MDA-A** = MDA Account Administrator (MDA_USER) — Manages an MDA's profile and users; submits and accepts work.
- **MDA-S** = MDA Staff (MDA_USER) — Submits and tracks requests within MDA policy.
- **AUD** = Auditor / Oversight Officer (OVERSIGHT) — Read-only oversight of records, decisions and audit trails.

## Row-level scoping (in addition to permissions)

| Data | Rule (src/modules/rbac/scope.ts) |
|---|---|
| Requests | `request.read.all` → all; `.department` → assigned department / project department; `.mda` → own MDA; `.own` → created by self within own MDA; assigned officers/assessors → their requests. Drafts visible only to creator. |
| Projects | `project.read.all` → all; `.department` → own/headed departments; `.mda` → own MDA (MDA staff: own requests only); `.assigned` → PM or active assignment. |
| MDAs | `mda.read.all`/`mda.review` → all; MDA users → own; KATDICT staff → MDAs of projects in scope. |
| Internal notes, tasks, risks, work logs, internal files | Never returned to MDA users (server-side stripping). |
| Knowledge | Published + visibility (ALL_USERS, KATDICT_ONLY for non-MDA, MDA_SPECIFIC for that MDA); managers see all. |
